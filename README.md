# vietnam-housing-analysis
Data Science analysis of Vietnamese property prices
# Vietnam Housing Market Analysis > COMP-140 Data Science · Alex Nguyen · May 2025 ## Overview A data-driven analysis of 30,229 Vietnamese property listings to understand what drives housing prices and predict them with machine learning.
## Project Structure - `data/` — raw dataset (CSV) - `notebooks/` — Jupyter notebook with full analysis - `reports/` — final PDF report 
## Key Results - Bathrooms (r=0.43) and Area are the top price drivers - Legal status contributes only 0.9% RF importance - Coastal cities average 15–30% above main metros - Random Forest: R²=0.31, RMSE=1.82B VND
